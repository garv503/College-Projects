# College Projects

Coursework projects. Each one lives on its own branch, so its code, history and README stay separate from the others.

> `main` holds nothing but this index. Pick a branch below to see an actual project.

## Projects

| Project | Branch | Stack |
| --- | --- | --- |
| **Foresight** — academic analytics. Marks and attendance go in; a ranked, explained view of which students need help comes out. | [`Student-Analytics`](../../tree/Student-Analytics) | Flask · MySQL 8 · vanilla JS · Docker |
| **Inkwell** — a fast, private notes app with email-verified signup, search, pinning and an admin console. | [`E-Notes`](../../tree/E-Notes) | React 18 · Express · MySQL |
| **Shivam Garments** — CSV-backed billing and store management for a garment shop. | [`Bill-Management-System`](../../tree/Bill-Management-System) | Python · pandas · matplotlib |

## Opening a project

Use the branch dropdown above the file list, or clone and check one out:

```bash
git clone https://github.com/garv503/College-Projects.git
cd College-Projects
git checkout Student-Analytics
```

Every branch carries its own README with full setup and run instructions.
