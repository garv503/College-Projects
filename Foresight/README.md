# Foresight

The full documentation for this project lives at the root of this branch: **[README.md](../README.md)**.

It covers the architecture, the database design, how risk scoring works, security notes and the API reference.

## Quick start

From the branch root:

```bash
cd Foresight
docker compose up --build
```

Then open <http://localhost:5000>.

Setup and operational guides sit beside this file: [setup.txt](setup.txt), [RUNNING.md](RUNNING.md) and [MySQL Code.txt](MySQL%20Code.txt).
